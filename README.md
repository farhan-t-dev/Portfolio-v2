# Farhan | Full Stack Developer & SysAdmin

A modern, high-performance portfolio showcasing specialized expertise in full-stack development, system administration, and scalable architectures.

## 🚀 Tech Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Supabase, PostgreSQL
- **Infrastructure:** Linux, Docker, Nginx, AWS
- **Tools:** TypeScript, Lucide React, Matter.js

## ✨ Key Features

- **Aesthetic Bento UI:** Modern layout with interactive magnetic components.
- **Dynamic Projects Archive:** Full-featured project showcase with immersive modal details.
- **Interactive Tech Orbit:** A visual representation of core technical skills and infrastructure knowledge.
- **Live Transmission Feed:** Functional Guestbook and Testimonials carousel.
- **Performance Optimized:** Lazy loading, optimized assets, and efficient animations.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file based on `.env.local.example` and add your Supabase credentials.

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
